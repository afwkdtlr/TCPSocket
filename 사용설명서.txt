TCP Socket Tool 사용 설명서
실행 파일: C:\TcpSocketTool\TcpSocketTool.exe

운영 중인 TCP 소켓과 전문을 주고받을 때 쓰는 도구입니다.
서버로 열어 두거나, 클라이언트로 상대에 접속할 수 있습니다.


1. 실행

TcpSocketTool.exe 를 더블클릭합니다.
처음 실행은 몇 초 걸릴 수 있습니다.
포트를 열 때 Windows 방화벽 창이 뜨면 허용합니다.

프로그램을 닫았다가 다시 켜면 마지막에 쓰던 IP, 포트, 구분자, 문자셋이 그대로 열립니다.
이 접속 설정은 C:\TcpSocketTool\config.json 에 저장됩니다.


2. 화면

위쪽
  TCP          통신 방식입니다. TCP만 됩니다.
  SERVER/CLIENT  서버로 들을지, 클라이언트로 붙을지 고릅니다.
  IP / PORT    주소와 포트입니다.
  BIND         서버일 때 포트를 엽니다. 연결 중이면 CLOSE 로 바뀝니다.
  CONNECT      클라이언트일 때 상대에 접속합니다. 연결 중이면 CLOSE 입니다.
  CLEAN        위쪽 로그만 지웁니다. 연결은 끊지 않습니다.

옵션
  DELIMITER       전문 앞뒤에 붙는 구분자입니다.
  송신 시 자동추가  켜 두면 보낼 때 구분자를 다시 입력하지 않아도 됩니다.
  문자셋           UTF-8 또는 ASCII. 기본값은 UTF-8 입니다.
  대상             오른쪽에 붙은 클라이언트가 보입니다. Ctrl+클릭으로 여러 곳을 고르고, 전체선택으로 모두에게 보냅니다.

가운데
  로그            접속, 송신, 수신이 여기 쌓입니다.
  전문            보관한 양식만 있습니다. 수신 내용은 여기 생기지 않습니다.
  STRING / BYTE   보낼 내용을 글자로 넣을지, 바이트로 넣을지 고릅니다.
  String Add      입력한 글을 STRING 칸에 그대로 붙입니다.
  Byte Add        입력한 바이트 하나를 BYTE 칸에 붙입니다.
  SEND            지금 선택된 탭의 내용을 보냅니다. Ctrl+Enter 도 같습니다.


3. 서버로 열기

1. SERVER 를 고릅니다. IP는 보통 0.0.0.0 입니다.
2. 포트를 입력합니다. 예: 35000
3. BIND 를 누릅니다.
4. 로그에 channelActive listen 0.0.0.0:35000 이 나오면 대기 중입니다.
5. 상대가 붙으면 channelActive 와 그 주소가 나옵니다.
6. 끊을 때는 CLOSE 를 누릅니다.

0.0.0.0 은 이 PC로 들어오는 모든 접속을 받는다는 뜻입니다.
이 PC 안에서만 시험할 때는 CLIENT 의 IP를 127.0.0.1 로 두면 됩니다.


4. 클라이언트로 붙기

1. CLIENT 를 고릅니다.
2. 상대 IP와 포트를 입력합니다.
3. CONNECT 를 누릅니다.
4. 로그에 channelActive 가 나오면 연결된 것입니다.
5. 끊을 때는 CLOSE 를 누릅니다.


5. 구분자

구분자는 한 번만 고릅니다. 송신 시 자동추가가 켜져 있으면 본문 끝에 자동으로 붙습니다.
이미 구분자가 붙어 있으면 한 번 더 붙이지 않습니다.

NULL (0x00)     기본값. 본문 뒤에 0x00 이 붙습니다.
LINE (CR LF)    본문 뒤에 0x0D 다음 0x0A. 10진수는 13 10 입니다.
STX/ETX         앞에 STX(0x02), 뒤에 ETX(0x03) 가 붙습니다.
CR (0x0D)       본문 뒤에 0x0D (10진수 13) 만 붙습니다.
LF (0x0A)       본문 뒤에 0x0A (10진수 10) 만 붙습니다.
없음            구분자를 붙이지 않습니다.
직접입력        바이트로 적습니다. 0D 0A, 13 10, \r\n 은 LINE과 같습니다.
                CRLF 라고 글자로 적으면 C, R, L, F 네 글자가 들어갑니다.

예. 구분자가 NULL 이고 자동추가가 켜진 상태에서 STRING에 - 를 넣고 SEND 하면
실제로 나가는 바이트는 45 0 입니다. 45는 '-' 이고 0은 NULL 입니다.

예. STX/ETX 에서 본문 - 를 보내면 바이트는 2 45 3 입니다.

받은 데이터는 구분자가 올 때까지 기다리지 않고, 도착하는 즉시 로그에 나옵니다.


6. 보내기

STRING으로 보내기
  1. STRING 탭을 엽니다.
  2. 전문 본문만 입력합니다. 구분자는 넣지 않아도 됩니다.
  3. SEND 를 누릅니다.
  로그에 send Byte 와 send String 이 남습니다.

BYTE로 보내기
  1. BYTE 탭을 엽니다.
  2. 바이트를 공백으로 구분해 입력합니다.
     10진수: 45 0
     16진수: 2D 00  또는  0x2D 0x00
  3. 아래 HEX 미리보기로 값을 확인합니다.
  4. SEND 를 누릅니다.
  자동추가가 켜져 있으면 여기 적은 값 뒤에도 구분자가 붙습니다.
  구분자까지 직접 넣고 싶으면 BYTE 칸에 같이 적습니다. 이미 있으면 중복해서 붙지 않습니다.

String Add
  오른쪽 칸에 글을 넣고 String Add 를 누릅니다.
  123 을 넣으면 STRING 칸에 123 이 그대로 붙습니다.
  49 50 51 같은 바이트로 바뀌지 않습니다.
  여러 번 누르면 이어서 붙습니다.

Byte Add
  오른쪽 칸에 바이트 하나를 넣고 Byte Add 를 누릅니다.
  예: 0, 45, 0x0A
  BYTE 칸 끝에 그 바이트가 붙고, BYTE 탭으로 이동합니다.

보낼 대상이 선택되지 않으면 "보낼 대상을 선택하세요" 가 나옵니다.
오른쪽에 붙은 주소가 보이고, Ctrl+클릭으로 여러 곳을 고른 뒤 SEND 합니다. 전체선택을 누르면 모두에게 보냅니다.


7. 받기

받은 내용은 위쪽 로그에만 나옵니다. 왼쪽 전문 목록에는 생기지 않고, 파일에도 저장되지 않습니다.

channelRead ... Byte:45 13 10
channelRead ... String:-

Byte 줄은 실제로 도착한 바이트를 10진수로 보여 줍니다.
String 줄은 그 바이트를 문자셋으로 읽은 글입니다. 구분자와 줄바꿈은 글자에서 빠져 있습니다.
서버일 때는 어느 주소에서 왔는지도 같이 나옵니다.

CLEAN 은 이 로그만 지웁니다.

수신 시 응답
  위쪽 수신 시 응답을 켜면, 데이터를 보낸 그 주소로만 답을 돌려줍니다.
  옆 칸을 비워 두면 방금 받은 바이트를 그대로 돌려줍니다.
  옆 칸에 글을 적으면 그 글을 현재 문자셋과 구분자 설정으로 보내 줍니다.
  응답은 왼쪽 전문 목록에 들어가지 않습니다. 로그에 send 와 주소가 보이면 그 소켓으로 실제로 나간 것입니다.
  상대 프로그램이 NULL 이면 여기 구분자도 NULL 이어야 상대 화면에 나타납니다. LINE 이면 CR LF 가 붙습니다.


8. 자주 쓰는 전문 보관

STRING에 양식을 만든 뒤 보관을 누릅니다.
왼쪽 전문 목록에 ★ 와 함께 추가되고, 바로 파일에 저장됩니다.

저장 위치: C:\TcpSocketTool\messages.json

프로그램을 껐다 켜도 ★ 목록은 다시 나타납니다.
항목을 선택하고 불러오기를 누르면 STRING 칸에 들어갑니다.
더블클릭해도 불러옵니다.
삭제하면 목록과 파일에서 함께 지워집니다.

수신된 전문은 이 목록에 넣지 않습니다.
보관은 STRING 칸의 내용만 저장합니다.


9. 로그에 나오는 말

channelRegistered     소켓이 준비되었습니다.
channelActive         서버가 대기 중이거나, 상대와 연결되었습니다.
channelRead           데이터를 받았습니다.
channelReadComplete   이번 수신 처리를 마쳤습니다.
channelInactive       연결이 끊어졌습니다.
channelUnregistered   소켓이 해제되었습니다.
exceptionCaught       오류입니다. 뒤에 나오는 문장이 원인입니다.
send                  보낸 내용입니다.


10. 자주 보는 상황

연결이 안 됩니다.
  IP와 포트가 맞는지 확인합니다.
  서버가 먼저 BIND 되어 있어야 클라이언트가 CONNECT 할 수 있습니다.
  방화벽에서 포트를 막지 않았는지 확인합니다.

보낸 것 같은데 상대가 못 받습니다.
  구분자가 상대 설정과 같은지 확인합니다.
  NULL이면 끝에 0x00, LINE이면 끝에 13 10, STX/ETX면 앞 2 뒤 3 입니다.
  로그의 send Byte 숫자로 실제 나간 값을 확인합니다.

글자가 깨집니다.
  문자셋은 UTF-8 또는 ASCII 입니다. 기본값은 UTF-8 입니다.

일부에게만 보내고 싶습니다.
  오른쪽 대상에서 보낼 주소만 클릭합니다.
  여러 곳이면 Ctrl 을 누른 채 클릭합니다. 전체선택은 모두에게 보냅니다.


11. 다른 PC에 전달

TcpSocketTool.exe 하나만 주면 실행됩니다. Python은 설치하지 않아도 됩니다.
저장해 둔 양식까지 넘기려면 messages.json 을 실행 파일과 같은 폴더에 같이 둡니다.
설명서는 사용설명서.docx 입니다. 없어도 프로그램은 실행됩니다.
